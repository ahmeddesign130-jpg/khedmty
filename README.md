# خِدمتي Khedmty — المرحلة الأولى

مشروع بداية فعلي لمنصة خِدمتي باستخدام Next.js App Router وTypeScript وTailwind CSS وPostgreSQL وPrisma.

## ما الموجود في هذه المرحلة؟

- واجهة رئيسية عربية RTL متجاوبة.
- صفحات إنشاء الحساب وتسجيل الدخول.
- API لإنشاء الحساب وتسجيل الدخول والخروج وقراءة الجلسة.
- تشفير كلمات المرور باستخدام bcrypt.
- جلسة موقعة داخل Cookie آمنة `HttpOnly`.
- منع التسجيل العام بصلاحية Super Admin.
- مخطط Prisma مبدئي يشمل المستخدمين والخدمات والطلبات والمدفوعات والمحادثات والتقييمات والإشعارات وسجل التدقيق.
- `.env.example` دون أسرار حقيقية.

## ما الذي لم يكتمل بعد؟

- إرسال رسائل تفعيل البريد واستعادة كلمة المرور يحتاج مزود بريد وإعداد مفاتيحه.
- لا يتم تفعيل الحسابات تلقائيًا؛ التسجيل ينشئ الحساب بحالة `PENDING` حتى إضافة تدفق تحقق البريد.
- لا يوجد إنشاء Super Admin تلقائيًا لمجرد تطابق البريد. إثبات ملكية البريد وتعيين الدور إداريًا سيُنفذان في مرحلة إعداد الإدارة.
- لم يُنفذ بعد Rate Limiting أو Google OAuth أو رفع الملفات أو لوحة الإدارة.
- هذه المرحلة لم تُختبر على قاعدة بيانات فعلية؛ لا تعتبر جاهزة للإنتاج قبل إكمال الإعداد والاختبارات الأمنية.

## المتطلبات

- Node.js 20.9 أو أحدث.
- PostgreSQL 14 أو أحدث.
- npm.

## التشغيل على كمبيوتر

1. فك ضغط المشروع.
2. انسخ `.env.example` إلى `.env`.
3. ضع رابط PostgreSQL حقيقيًا في `DATABASE_URL`.
4. أنشئ قيمة عشوائية طويلة لـ `AUTH_SECRET` (32 حرفًا على الأقل).
5. افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
npm install
npx prisma generate
npx prisma db push
npm run dev
```

افتح `http://localhost:3000`.

## النشر

ارفع ملفات المشروع إلى GitHub، ثم اربط المستودع بمنصة استضافة تدعم Next.js (مثل Vercel)، وأضف متغيرات البيئة في إعدادات الاستضافة. أنشئ PostgreSQL مُدارًا، ثم نفّذ `npx prisma db push` أو استخدم migrations بعد إعدادها.

## تنبيه مهم للأمان

لا ترفع ملف `.env` أو أي مفاتيح أو كلمات مرور إلى GitHub. ارفع `.env.example` فقط. لا تمنح دور `SUPER_ADMIN` من واجهة التسجيل أو من بيانات يرسلها المستخدم.
